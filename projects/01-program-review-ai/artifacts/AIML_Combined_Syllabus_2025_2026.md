> **Program:** Associate of Applied Science in Artificial Intelligence  
> **Course Prefixes:** AIML (Artificial Intelligence & Machine Learning)  
> **Author & Lead Designer:** Trevor Swarm  

---

## Course Overviews & Measurable Learning Competencies

### 1. AIML 1010: Introduction to Artificial Intelligence (3 Credits)
* **Format:** Low-barrier conceptual and applied overview.
* **Core Competencies:**
  * Explain the historical development and foundational categories of artificial intelligence.
  * Evaluate real-world problem domains appropriate for rule-based systems vs. statistical machine learning.
  * Demonstrate effective prompt engineering and human-in-the-loop workflows using foundational LLMs.
  * Construct basic visual decision trees and heuristic algorithms without requiring low-level syntax.

### 2. AIML 1020: Artificial Intelligence Ethics & Society (3 Credits)
* **Format:** Interdisciplinary seminar addressing governance, fairness, and risk.
* **Core Competencies:**
  * Analyze systemic bias, training data provenance, and disparate algorithmic impact.
  * Evaluate intellectual property rights, data sovereignty, and copyright law in generative AI.
  * Formulate comprehensive algorithmic risk assessments for commercial and public sector AI deployments.
  * Articulate professional ethical responsibilities aligned with the ACM Code of Ethics.

### 3. AIML 1100: Machine Learning Foundations (3 Credits)
* **Format:** Applied Python programming with Scikit-Learn.
* **Core Competencies:**
  * Implement supervised learning pipelines (linear regression, decision trees, random forests, SVMs).
  * Execute data preprocessing, feature normalization, train-test splitting, and cross-validation.
  * Evaluate model performance using confusion matrices, precision-recall curves, and ROC-AUC.
  * Interpret unsupervised clustering models (K-Means, PCA dimensionality reduction).

### 4. AIML 2100: Deep Learning & Neural Networks (3 Credits)
* **Format:** Advanced applied deep learning using PyTorch and TensorFlow.
* **Core Competencies:**
  * Construct multi-layer perceptrons (MLPs), backpropagation mechanics, and activation functions.
  * Optimize model convergence using loss functions, learning rate schedules, and dropout regularization.
  * Build convolutional neural networks (CNNs) for structured feature extraction.
  * Deploy fine-tuned pre-trained weights for transfer learning applications.

### 5. AIML 2200: Computer Vision (3 Credits)
* **Format:** Image processing, object detection, and edge computing.
* **Core Competencies:**
  * Process image and video streams using OpenCV and Python.
  * Implement real-time object detection and segmentation (e.g. YOLO, Mask R-CNN).
  * Deploy edge-vision models to localized hardware environments.

### 6. AIML 2300: Natural Language Processing (3 Credits)
* **Format:** Text analysis, embeddings, and Transformer architectures.
* **Core Competencies:**
  * Clean, tokenize, and vectorize unstructured textual data.
  * Implement semantic search and retrieval using vector embeddings and vector databases.
  * Build Retrieval-Augmented Generation (RAG) pipelines for specialized knowledge domains.

### 7. AIML 2900: Applied AI Capstone (3 Credits)
* **Format:** Industry-partner client project and oral defense.
* **Core Competencies:**
  * Manage an end-to-end technical project lifecycle from client scoping to deployment.
  * Produce comprehensive technical documentation and system architecture diagrams.
  * Deliver a formal, live public presentation defending technical decisions and ethical guardrails.
